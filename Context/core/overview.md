## O que é

`assistance-agent` é um projeto de software para construir um **assistente/agente de IA em código**.

O projeto está na **fase zero**: o repositório foi criado vazio em 2026-11-19 e, até agora, contém apenas a infraestrutura de contexto para agentes (`AGENTS.md`, `CLAUDE.md`, `Context/`). Ver `CTX-FCT-20261119-repository-initialized`.

## Componentes previstos (áreas de conhecimento)

- **Design do agente** — comportamento, prompts, ferramentas, memória → `branches/agent-design/`
- **Integrações** — provedor(es) de LLM e serviços externos → `branches/integrations/`
- **Infraestrutura** — stack, runtime, deploy, tooling → `branches/infrastructure/`

Essas áreas são a divisão inicial de conhecimento, não uma arquitetura decidida.
